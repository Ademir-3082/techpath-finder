# 🧭 TechPath Finder

Aplicação web desenvolvida em **PHP** para ajudar pessoas a explorar possíveis caminhos profissionais na área de tecnologia por meio de decisões, sinais e experimentação prática.

🔗 **Aplicação online:**  
https://dev.funilpro.com.br/techpath-finder

---

## 💡 Sobre o projeto

O **TechPath Finder** foi desenvolvido para transformar respostas a situações práticas em sinais que auxiliam o usuário na exploração de diferentes áreas da tecnologia.

Em vez de indicar uma profissão como resposta definitiva, a aplicação trabalha com **hipóteses de caminhos**, permitindo que o usuário explore possibilidades e valide interesses por meio de experimentos práticos.

O fluxo completo da aplicação é:

**Início → 12 perguntas situacionais → Resultado → Mapa de tendências → Roadmap personalizado**

## 🗺️ TechPath Roadmap

Após concluir o Finder, o usuário recebe um resultado baseado nos sinais identificados durante as 12 etapas.

A partir desse resultado, o sistema permite gerar um **Roadmap personalizado**, transformando as hipóteses encontradas em próximos passos de exploração.

O objetivo é permitir que o usuário:

- entenda quais caminhos vale a pena investigar;
- realize pequenos experimentos práticos;
- observe evidências do próprio desempenho;
- organize os próximos passos de aprendizagem;
- valide hipóteses antes de tomar decisões de longo prazo.

## 🧠 Conceito do projeto

O **TechPath Finder** não foi criado como um teste psicométrico ou como uma ferramenta que determina qual profissão uma pessoa deve seguir.

A proposta é trabalhar com:

**Sinal → Hipótese → Experimento → Evidência → Comparação → Decisão**

Dessa forma, o usuário pode explorar diferentes possibilidades antes de escolher uma direção profissional.

## ▶️ Executando o projeto

O projeto utiliza **PHP** e pode ser executado em um servidor web com suporte à linguagem.

Também é possível executá-lo localmente utilizando o servidor embutido do PHP:

```bash
php -S localhost:8000
```

Depois, acesse:

```text
http://localhost:8000
```
